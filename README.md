# ผู้ช่วย AI สำนักงาน (เว็บตัวอย่าง)

เว็บตัวอย่างที่เรียกใช้ AI ผ่าน API แบบเดียวกับ OpenAI (`chat.completions`) เพื่อช่วยงานสำนักงาน สร้างด้วย Python + Flask
ไม่ต้องมีฐานข้อมูล ข้อมูลเอกสารเก็บเป็นไฟล์ในโฟลเดอร์ `data/docs`

> เว็บนี้เป็น **ตัวอย่างสำหรับทดลองใช้งาน** ยังไม่มีระบบล็อกอินหรือกำหนดสิทธิ์ ใครเข้าเว็บได้ก็ใช้ได้ทุกฟังก์ชันและเห็นเอกสารทั้งหมด

## ฟังก์ชันที่มี

| หน้า | ที่อยู่ | ทำอะไรได้ |
|---|---|---|
| หน้าแรก | `/` | Banner ลิงก์ไปยังทุกฟังก์ชัน |
| แชทกับ AI | `/chat` | ถามตอบทั่วไป จำบริบทในหน้าเดียวกัน |
| ตรวจและปรับภาษา | `/proofread` | แก้คำผิด ปรับสุภาพ/กระชับ/ทางการ ไฮไลต์ส่วนที่แก้ อัปโหลดไฟล์ .docx ได้ |
| ช่วยเขียน | `/write` | อีเมล ประกาศ โพสต์โซเชียล รายงาน หนังสือราชการ บันทึกข้อความ หนังสือเชิญประชุม |
| ถามตอบจากเอกสาร | `/ask` | อัปโหลดระเบียบ/คู่มือ (.pdf .docx .txt .md) แล้วถาม พร้อมอ้างอิงแหล่งที่มา และสร้างคำถามแนะนำจากเอกสาร |
| สรุปการประชุม | `/meeting` | สรุปประเด็น มติ งานที่ต้องทำ ส่งออกเป็น .docx |
| ตรวจเอกสารเสนอราคา | `/bidding` | คัดกรองเอกสาร e-bidding: ความครบถ้วน ความสอดคล้องของข้อมูล สรุปข้อสังเกต ส่งออกเป็น .docx |

ทุกหน้ามีช่อง **โมเดล** ให้เลือกโมเดล AI ได้ (รายการดึงจากบริการโดยตรง) ค่าเริ่มต้นคือ `gemini-2.5-flash-lite`

## สิ่งที่ต้องมี

- **Windows** (ไฟล์ `run.bat` ใช้กับ Windows; ระบบปฏิบัติการอื่นรันด้วยคำสั่งด้านล่างได้)
- **Python 3.10 ขึ้นไป** ดาวน์โหลดที่ https://www.python.org/downloads/ ตอนติดตั้งให้ติ๊ก **Add Python to PATH**
- **API Key** ของบริการ AI (ขอจากผู้ดูแลบริการ)
- เครื่องต้องเชื่อมต่ออินเทอร์เน็ต และเข้า `gen.ai.kku.ac.th` ได้

## วิธีติดตั้งและรัน (แบบง่าย)

1. คัดลอกโฟลเดอร์ `webdemo` ทั้งโฟลเดอร์ไปไว้ที่เครื่อง (ที่ไหนก็ได้)
2. ดับเบิลคลิก **`run.bat`**
3. ครั้งแรกโปรแกรมจะติดตั้งไลบรารีให้เอง (ใช้เวลาสักครู่) แล้วถาม **API Key** ให้วางคีย์แล้วกด Enter
4. เบราว์เซอร์จะเปิดที่ http://127.0.0.1:5000 เอง

ปิดโปรแกรมโดยกด `Ctrl+C` หรือปิดหน้าต่างสีดำ

คีย์ที่กรอกผ่าน `run.bat` ใช้เฉพาะรอบนั้น **ไม่ถูกบันทึกลงไฟล์** จึงต้องกรอกใหม่ทุกครั้งที่เปิด
ถ้าไม่อยากกรอกทุกครั้ง ให้ตั้งเป็นตัวแปรของผู้ใช้ครั้งเดียว (เปิด PowerShell แล้วพิมพ์):

```powershell
setx API_KEY "คีย์ของคุณ"
```

จากนั้นปิดหน้าต่างทั้งหมดแล้วดับเบิลคลิก `run.bat` ใหม่ จะไม่ถามคีย์อีก

## วิธีติดตั้งและรัน (แบบพิมพ์คำสั่งเอง)

```powershell
cd webdemo
pip install -r requirements.txt
$env:API_KEY = "คีย์ของคุณ"
python app.py
```

แล้วเปิด http://127.0.0.1:5000

บน macOS/Linux:

```bash
cd webdemo
pip3 install -r requirements.txt
export API_KEY="คีย์ของคุณ"
python3 app.py
```

## การตั้งค่า

ตั้งผ่านตัวแปรสภาพแวดล้อมก่อนรัน

| ตัวแปร | จำเป็น | ความหมาย |
|---|---|---|
| `API_KEY` | ใช่ | คีย์ของบริการ AI |
| `PORT` | ไม่ | พอร์ตของเว็บ (ค่าเริ่มต้น 5000) ใช้เมื่อพอร์ตชนกับโปรแกรมอื่น |
| `NO_BROWSER` | ไม่ | ตั้งเป็น `1` เพื่อไม่ให้ `run.bat` เปิดเบราว์เซอร์อัตโนมัติ |

ที่อยู่บริการ (`BASE_URL`) และโมเดลเริ่มต้น (`MODEL`) อยู่ต้นไฟล์ `app.py` แก้ได้ที่นั่น

├─ sample_bids/       ข้อมูลจำลองสำหรับลองหน้าตรวจเอกสารเสนอราคา (มีไฟล์เฉลยจุดผิด)

## การใช้งานหน้าถามตอบจากเอกสาร

- กด **+ เพิ่มเอกสาร** หรือลากไฟล์มาวาง รองรับ `.pdf` `.docx` `.txt` `.md`
- ไฟล์ตัวอย่าง `ตัวอย่าง_ระเบียบจัดซื้อจัดจ้าง(จำลอง).txt` **เป็นข้อมูลสมมติ ไม่ใช่ระเบียบจริง** ลบทิ้งได้ด้วยปุ่ม ×
- ระบบค้นหาด้วยการจับคู่ข้อความ (ไม่ใช้ embedding เพราะบริการไม่รองรับ) ถามด้วยคำใกล้เคียงกับในเอกสารจะได้ผลดีกว่า
- PDF ที่เป็นภาพสแกนอ่านไม่ได้ ต้องทำ OCR ก่อน และ PDF ภาษาไทยบางไฟล์อาจดึงข้อความเพี้ยน ควรทดลองถามดูก่อนใช้งานจริง
- เมื่อเปลี่ยนชุดเอกสาร คำถามแนะนำจะถูกสร้างใหม่อัตโนมัติ

## การใช้งานหน้าตรวจเอกสารเสนอราคา (e-bidding)

1. **ขั้นที่ 1** วางข้อความเกณฑ์/TOR (หรือเลือกไฟล์) แล้วกด "สกัดรายการเอกสารที่ต้องยื่น" จากนั้นตรวจและแก้รายการในตารางได้ (ติ๊กจำเป็น/ไม่จำเป็น ใส่อายุสูงสุดของเอกสารเป็นเดือน)
2. **ขั้นที่ 2** ใส่วันที่ยื่นข้อเสนอ เพิ่มผู้ยื่นแต่ละราย แล้วเลือกไฟล์หรือโฟลเดอร์ของรายนั้น หรือเลือก "โฟลเดอร์รวม" ที่มีโฟลเดอร์ย่อยรายละหนึ่งโฟลเดอร์ ระบบจะแยกผู้ยื่นให้เอง
3. กด **เริ่มตรวจ** ดูความคืบหน้า แล้วอ่านผลรายผู้ยื่น (รายการเอกสาร ข้อสังเกตเรียงตามระดับ สูง/กลาง/ต่ำ พร้อมหลักฐานที่อ้างถึงไฟล์) ดาวน์โหลดเป็น Word ได้

หลักการทำงาน: AI ทำหน้าที่จัดประเภทไฟล์และดึงข้อมูล (เลขนิติบุคคล ชื่อ วันที่ ตารางราคา) ส่วนการเทียบและคำนวณทั้งหมดทำด้วยโค้ด
(เช่น ผลคูณจำนวน×ราคา ยอดรวม ตัวเลขเทียบตัวอักษร หลักตรวจเลข 13 หลัก อายุเอกสาร วันหมดอายุเทียบวันยื่น) และข้อความหลักฐานที่ AI อ้างจะถูกตรวจว่ามีอยู่ในไฟล์จริง

**ขอบเขตและข้อจำกัด**
- เป็นการ**คัดกรองเบื้องต้น** ไม่ตัดสินผ่าน/ไม่ผ่าน ผลทุกข้อต้องให้คณะกรรมการตรวจกับเอกสารต้นฉบับ
- ไม่ตรวจลายมือชื่อ ตราประทับ หรือเนื้อหาในรูปภาพ และยังไม่ได้ทำ OCR ไฟล์สแกน/PDF ที่ไม่มีข้อความจะถูกแจ้งว่า "ต้องตรวจเอง"
- ยังไม่เทียบราคาข้ามผู้ยื่น ยังไม่มีประวัติ/ล็อกอิน ไฟล์ถูกเก็บในหน่วยความจำชั่วคราว (ไม่บันทึกลงดิสก์) และผลหมดอายุหลังประมาณ 2 ชั่วโมงหรือเมื่อรีสตาร์ตเซิร์ฟเวอร์ ให้ดาวน์โหลดรายงานไว้ก่อน
- จำกัดไม่เกิน 400 ไฟล์ต่อครั้ง 30 ผู้ยื่น และไฟล์ละ 25 MB · ข้อความของไฟล์จะถูกส่งไปยังบริการ AI ภายนอก ตรวจสอบนโยบายข้อมูลก่อนใช้กับเอกสารจริง
- ลองกับข้อมูลจำลองได้ที่ `sample_bids/` (วางเนื้อหา `TOR_ตัวอย่าง.txt` ในขั้นที่ 1 แล้วเลือกโฟลเดอร์ `ผู้ยื่น` เป็นโฟลเดอร์รวม วันที่ยื่น 15 ต.ค. 2569) เทียบผลกับ `เฉลยจุดผิด.txt` สร้างข้อมูลใหม่ได้ด้วย `python sample_bids/make_samples.py` ทั้งหมดเป็นข้อมูลสมมติ

## ข้อควรระวัง

- **คีย์ API เป็นความลับ** อย่าใส่ลงในไฟล์โค้ด อย่าอัปโหลดขึ้น GitHub หรือส่งต่อในแชท ถ้าคีย์หลุดให้ขอคีย์ใหม่ทันที
- ผลลัพธ์จาก AI **อาจผิดพลาด** โดยเฉพาะชื่อ วันที่ ตัวเลข และข้อกฎหมาย ต้องมีคนตรวจก่อนนำไปใช้จริง
- หนังสือราชการที่สร้างเป็นโครงทั่วไป ยังไม่ได้ปรับให้ตรงกับแบบของหน่วยงาน และจะมีตัวยึด เช่น `[เลขที่หนังสือ]` ให้เติมเอง
- เอกสารและข้อความที่ใส่จะถูกส่งไปยังบริการ AI ภายนอก อย่าใส่ข้อมูลส่วนบุคคลหรือข้อมูลลับ หากยังไม่ได้ตรวจสอบนโยบายข้อมูลของบริการ
- เว็บนี้ไม่มีระบบล็อกอิน **อย่าเปิดให้คนอื่นหรืออินเทอร์เน็ตเข้าถึง** โดยตรง ใช้บนเครื่องตัวเองหรือเครือข่ายที่เชื่อถือได้เท่านั้น
- GitHub Pages รัน Flask ไม่ได้ (รองรับเฉพาะไฟล์สถิต) หากต้องการให้ผู้อื่นเข้าถึง ต้องนำไปรันบนเซิร์ฟเวอร์ที่รองรับ Python

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| `ไม่พบ Python` | ติดตั้ง Python แล้วติ๊ก Add Python to PATH จากนั้นเปิด `run.bat` ใหม่ |
| ติดตั้งไลบรารีไม่สำเร็จ | ตรวจอินเทอร์เน็ต/พร็อกซี แล้วรัน `run.bat` ใหม่ หรือสั่ง `pip install -r requirements.txt` ดูข้อความผิดพลาด |
| `Address already in use` / พอร์ตชน | ปิดโปรแกรมที่ใช้พอร์ต 5000 หรือตั้ง `PORT` เป็นเลขอื่น เช่น `set PORT=5050` แล้วรัน |
| ขึ้น "ยังไม่ได้ตั้งค่าตัวแปร API_KEY" | รันผ่าน `run.bat` แล้วกรอกคีย์ หรือตั้ง `API_KEY` ตามหัวข้อการตั้งค่า |
| "เรียก API ไม่สำเร็จ" (401/403) | คีย์ผิดหรือหมดอายุ ขอคีย์ใหม่ |
| "เรียก API ไม่สำเร็จ" (เชื่อมต่อไม่ได้) | เครื่องอาจเข้า `gen.ai.kku.ac.th` ไม่ได้ ลองเครือข่ายอื่น หรือสอบถามผู้ดูแลบริการ |
| โมเดลบางตัวตอบรูปแบบเพี้ยน | เปลี่ยนโมเดลในช่อง "โมเดล" หรือกดลองใหม่ |
| หน้าเว็บค้างที่ "กำลังโหลด" | ตรวจว่าหน้าต่างสีดำของ `run.bat` ยังเปิดอยู่และไม่มีข้อความผิดพลาด |
